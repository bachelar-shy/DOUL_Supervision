## 사용 방법
1. GitHub Actions의 `preview-pr169-173-integrated-ui` 실행 결과에서 CI와 화면 캡처를 확인합니다.
2. Pages 배포가 성공했다면 GitHub Pages 미리보기 사이트에서 메뉴를 눌러봅니다.
3. 그렇지 않으면 `doul-pr169-173-static-ui-preview` 웹 빌드 및 `doul-pr169-173-ui-screenshots`을 GitHub Actions Artifact로 내려받아 확인합니다.
4. 테스트 UI에서 **감리보고 > 감리 양식**, **현장기록 > 파일 선택**, **검측·검수 > 시공사 역할**을 순서대로 확인합니다.
