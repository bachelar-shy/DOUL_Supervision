# DOUL Supervision 용어사전 v0.4 — 반영 준비

현재 이 브랜치는 용어사전 적용을 위한 작업 위치만 생성했습니다. **592개 용어 데이터는 아직 GitHub에 업로드되지 않았습니다.**

## 예정 산출물
- `terms.json`: 592개 용어 앱 적재 데이터
- `terms.csv`: 운영자 검수용 데이터
- `app-mapping-template.csv`: UI 용어 매핑 템플릿
- `validation.json`: 데이터 점검 결과

## 원칙
- 개별 정의 보완은 후속 작업
- 기존 API/DB 영구 식별자는 변경하지 않음
- 미검수 번역은 확정된 다국어 표현으로 취급하지 않음
- 실제 화면 매핑과 배포는 별도 검증 후 진행
