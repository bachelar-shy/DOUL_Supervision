# DOUL 감리앱 — Fieldwire 화면 비교 검증 기록 기준

## 목적

색상·로고는 DOUL 브랜드를 유지하고, **Fieldwire 웹/모바일의 화면 구획, 메뉴 위치, 도구 순서, 목록 밀도, 오른쪽 상세 패널과 팝업 동작**을 비교한다. GitHub UI 시험은 기하학적 오류를 검사하는 수단이며 **Fieldwire와의 시각적 일치 여부를 자동 확정하지 않는다**.

## 이번 자동 수집

- 데스크톱 1440×900, 모바일 390×900에서 도면을 제외한 **16개 업무 메뉴 × 2개 화면 = 32개 캡처** 수집.
- 768/1024/1920px에서는 메뉴별 상단·본문 정렬과 수평 넘침을 추가 검증.
- GitHub Actions `ui-resizable-workspaces`의 `fieldwire-nondrawing-layout-screenshots` 자료로 보관.
- 로그인/설정/문서 작성/현장기록의 상세 버튼·폼 캡처는 각각 별도 CI의 증빙을 사용한다.

대상 메뉴:
오늘 / 검측·검수 / 현장·증빙 / 현장 확인 대기 / 지적사항 / 시정조치 / 공정 / 계약·클레임 / 기성·지급 / 준공·인계 / 안전·작업허가 / 발주처 보고 / 문서 작성 / 관리대장 / 설계질의 / 인원 추가 요청.

## 수동 검수 항목

| 구분 | 비교해야 할 요소 | 합격 기준 |
|---|---|---|
| 좌측 메뉴 | 위치·폭·아이콘·선택 강조·접기/펼치기 | 동일한 탐색 구조와 안정적인 상태 전환 |
| 상단 메뉴 | 명령줄 높이·검색·경로·프로젝트/계정 위치 | 모든 화면에서 동일 기준선 |
| 목록 | 행 높이·필터·검색·정렬·선택·페이지 이동 | 많은 업무에서도 조밀한 행과 일정한 간격 |
| 상세 | 오른쪽 패널 위치·폭·닫기·목록 복귀 | 목록 스크롤을 보존하고 다른 패널을 침범하지 않음 |
| 양식/문서 | 버튼·텍스트 필드·선택창·미리보기·출력 | 조작 위치가 안정적이고 정보가 숨지 않음 |
| 스크롤 | 메뉴/목록/본문/우측 패널/표 가로 스크롤 | 각 작업영역이 독립적으로 스크롤 |
| 팝업 | 열기·닫기·초점·크기·배경 작업면 유지 | 작업 맥락 보존, 겹침으로 인한 조작 차단 없음 |
| 모바일 | 상단/하단 탐색, 터치 영역, 세로 배치 | 44px 목표 터치 크기와 가로 넘침 방지 |
| 색상 | DOUL 배경·텍스트·선택색·알림색 | Fieldwire 색상은 복제하지 않고 DOUL 기준 유지 |

## 미완료·별도 담당 범위

- **도면의 PDF 장 분리, 마크업, 개정 이력, 이슈 핀, 도면번호 추출은 기존 도면 개발 PR에서 계속 담당**한다. 이 검증 PR에서 해당 파일을 변경하지 않는다.
- 공식 Fieldwire 화면 및 사용자 제공 참조화면과 동일 해상도에서 직접 대조한 후에만 **UI 일치 완료**를 판정한다.
- 동일 색상·동일 글꼴·동일 데이터가 아닌 상태에서 픽셀 단위 완전 일치를 선언하지 않는다. 대신 구성 요소의 상대 좌표·크기·동작을 검증한다.

## 검수 결과 입력 형식

화면명 / 기준 해상도 / 좌측 메뉴 / 상단 조작 / 목록 / 상세 또는 팝업 / 스크롤 / 버튼·입력 / 모바일 / 판정(PASS·보완필요) / 수정 PR.

CI 캡처는 현황 증빙이며 실제 Fieldwire 참조화면 비교·검수 결과는 별도 기록한다.
