# DOUL 감리앱 — Fieldwire UI 배치·컴포넌트 일치 기준 v1

## 적용 결정
- Fieldwire의 **화면 레이아웃, 요소 위치, 정보 밀도, 도구 배열, 사용자 상호작용**을 가능한 한 동일하게 적용한다.
- 브랜드명·로고·주요 선택 및 실행 색상은 DOUL 스타일을 유지한다. Fieldwire 전용 이미지·상표·원본 소스/그래픽은 재사용하지 않는다.
- UI만 변경한다. 기존 프로젝트·역할 권한, 데이터 모델, 서버 상태, 승인 및 검측 업무 규칙은 바꾸지 않는다.
- 이 문서의 픽셀 값은 Fieldwire 공식 사양이 아니라 **DOUL 구현 기준값**이다. 실제 화면별 레퍼런스 비교 후 보정한다.

## 화면 구성 원칙

| 화면 영역 | 위치·구성 | DOUL 적용 |
|---|---|---|
| 프로젝트/업무 탐색 | 항상 좌측 수직 메뉴 | 208px 데스크톱, 64px 접힘/태블릿, 모바일 Drawer |
| 공통 상단 | 화면 전체의 얇은 가로 영역 | 48px; 메뉴 경로, 검색, 언어·계정 및 상태 표시 |
| 메뉴별 명령 | 본문 맨 위의 수평 도구줄 | 화면별 액션이 같은 높이/방향/간격으로 표시 |
| 중심 작업 영역 | 화면 가로·세로 대부분 점유 | 카드 꾸밈보다 표·목록·문서·도면 정보 우선 |
| 보조·상세 정보 | 가능하면 우측 패널 | 선택한 이슈/문서/검측의 상세; 배경 작업면 유지 |
| 도면 수직 도구 | 캔버스 왼쪽 상단 | 검은색 수직 도구막대, 선택형 버튼 상태, Tooltip |
| 도면 이슈 목록 | 도면 오른쪽 끝 | 데스크톱 목표 폭 270~320px, 독립 스크롤 |
| 도면 하단 조작 | 캔버스 하단 | 이전/다음, 도면번호·도면명, 현재 위치 및 버전 |
| 팝업 | 사용 중인 화면 위 | 현재 작업 위치 보존, 닫으면 원래 화면으로 복귀 |
| 모바일 | 중심 작업 유지, 패널 접기 | 44px 이상 터치영역, 우측 목록은 슬라이드 패널 |

## 컴포넌트 기준

| 종류 | 크기/밀도 | 기본 동작 |
|---|---|---|
| 주요/보조 버튼 | 높이 34px | Hover/Pressed/Disabled/Loading 구분 |
| 아이콘 버튼 | 34x34px | Tooltip, 제목, 키보드 포커스 |
| 도면 도구 버튼 | 34x34px | 선택된 도구 유지; DOUL Blue 강조 |
| 검색/선택 입력 | 34px | 검색, 자동완성, 비활성, 오류 상태 |
| 목록 행 | 평균 40~44px | Hover 강조, 선택 시 파란 강조선 |
| 도면 이슈 행 | 최소 49px | 선택한 핀과 같은 항목 강조 |
| 표 | 고정 헤더, 조밀한 셀 | 열 정렬/필터/가로 스크롤 |
| 탭 | 최소 34px | 선택 상태, 탭 아래 강조선 |
| Scrollbar | 얇은 약 7px | 패널별 독립 스크롤, 조작 가능 |
| 다이얼로그/메뉴 | 작은 radius, 얇은 테두리 | 현재 화면 유지, Escape 및 닫기 |
| 상태 라벨 | 작은 배지 | 텍스트 + 서버 상태색 (색만으로 의미 전달 금지) |
| 휴대폰 조작 | 최소 44px | 엄지 터치, 화면 넘침 방지 |

## DOUL 컬러 예외
- 주요 액션·선택 상태: 기존 `--doul-color-brand` / DOUL Blue.
- 메뉴·마크업 도구 배경: 진회색 무채색.
- 본문 배경: 연회색, 주요 데이터 영역은 흰색.
- 오류·주의·완료 등 업무 상태색: 서버가 제공하는 의미를 그대로 유지.
- UI 크기 조정이 필요하더라도 현장 업무 식별성/접근성을 떨어뜨리지 않는다.

## 적용 순서
1. **공통 컴포넌트 (이번 PR)**: 버튼·입력·탭·메뉴·표·스크롤바, 상단/좌측 구조, 도면 좌/중/우 배치 기준 및 독립 스크롤.
2. **도면 전용 기능 (기존 병렬 PR과 통합)**: 원본 PDF별 장 등록/추출, 도구막대의 마크업·핀, 이슈 클릭 상세 모달, 도면 개정/버전 비교, 도구 하위 메뉴.
3. **전체 메뉴 적용**: 현장기록·검측·시정조치·감리보고·문서·설정·관리대장까지 한 화면 틀로 정리.
4. **브라우저 시각 비교**: 동일한 해상도(390/768/1024/1440/1920), 같은 유형의 화면/데이터를 놓고 항목별 좌표, 크기, 밀도, 선택/닫기/스크롤 동작 비교·재수정.

## 현재 구현과 미완료 구분

- 본 PR은 CSS와 UI 회귀시험으로 **공통 배치/크기 규칙을 정리**한다. 모든 메뉴의 육안·픽셀 단위 일치 검증을 통과했다는 뜻이 아니다.
- 도면 모달·마크업·표제란 추출 등의 구현은 각각 열린 PR #205, #206, #207을 통합한 후 별도 사용성 시험으로 검증해야 한다.
- 추후 PR에서도 공통 레이아웃을 화면별 복제하지 말고 `apps/web/src/design/fieldwire-parity.css` 및 공통 UI 컴포넌트에 반영한다.
- Fieldwire 브랜드 복제 없이 레이아웃·상호작용 방식만 기준으로 삼는다.
