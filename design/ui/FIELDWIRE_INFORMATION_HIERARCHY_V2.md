# DOUL 감리앱 — 화면 정보 계층 및 반복 제목 제거 v2

## 현장 기준

- **현재 메뉴 제목은 본문 최상단 h1에 한 번만 표시한다.**
- 공통 상단 탐색 경로는 \`DOUL / 현장명(프로젝트명)\`으로 구성한다. 현재 메뉴명을 두 번째로 출력하지 않는다.
- 검색·필터·정렬이 있는 업무 목록은 목록 도구줄에 결과 건수를 표시하며, \`부적합·지적사항 목록\` 같은 반복된 제목을 출력하지 않는다.
- 공정·계약·기성·준공의 탭은 업무 분류 이름을 제공한다. 선택된 탭명을 목록 제목으로 재표시하지 않고 건수를 표시한다.
- 보기 전환은 접근 가능한 버튼으로 제공하되 데스크톱에서 압축된 아이콘 형태를 사용하고 모바일 터치 목표 44px을 유지한다.
- 기록 제목·상태·현재 버전·담당 범위, 필요한 위험 안내와 권한 오류는 삭제하거나 숨기지 않는다.

## 중복 제목에 대한 예외

- 작업을 여는 **상세 패널의 개별 기록 제목**은 메뉴명과 다른 데이터이므로 보존한다.
- 프로젝트명은 상단 탐색 경로와 메뉴의 현장 선택기에 함께 표시될 수 있다. 메뉴명 중복과 달리 실제 작업 범위 확인에 필요하다.
- 모바일에서 탐색 경로가 생략되더라도 본문 현재 메뉴 제목 및 기능 도구는 유지한다.
- 도면 뷰어의 도면번호·도면명·개정 차수는 데이터 식별정보다. 동일 규칙을 적용하여 제거하지 않는다.

## 검증 기준

| 구분 | 확인 |
| --- | --- |
| 공통 상단 | 현재 메뉴명 재표시 없음, 실제 선택한 프로젝트명 표시 |
| 목록 | 페이지 h1 한 번, 검색/필터와 결과 건수 유지 |
| 공정 등 분류형 목록 | 분류 탭과 목록 제목 중복 없음, 항목 수 유지 |
| 보기 전환 | 목록·분할·상세 전환 작동 및 ARIA 라벨 유지 |
| 상세 패널 | 선택된 기록 제목과 상태, 목록 복귀 유지 |
| 반응형 | 390/768/1024/1440/1920px에서 본문 가로 넘침 없음 |
| 업무 계약 | 기존 역할·서버 검증·원본·검측·승인·저장 계약 변경 없음 |

## 통합 주의

위 요구는 개별 브랜치로 나누어 적용한다. \`main\`으로 병합할 때는 해당 브랜치의 브라우저/업무 계약 CI 통과와 기존 도면/현장기능 병렬 PR의 변경 파일 충돌 여부를 재확인한다. 화면 배치 검증은 Fieldwire 원본과의 픽셀 일치를 자동 보장하지 않는다.
