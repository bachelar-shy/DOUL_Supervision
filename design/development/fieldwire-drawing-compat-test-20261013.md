# Fieldwire 3차 감리·도면 기능 병행 호환성 시험
기준: 2026-10-13 / **TEST ONLY — 운영 병합용 PR 아님**

## 상호 작용 범위
- 감리 #230: 사진↔도면 핀 이동, 협업 기록, 오프라인 입력
- 감리 #231·#233: 최신 버전 확인, 캡처 JSX, 한/베/영 공통 문구
- 도면 #206: 마크업 그리기·저장·복원
- 도면 #216: 원본 개정 이력
- 도면 #224: PDF 표제란 정보 검수
- 도면 #226: 도면번호/제목 인식 엔진(서로 직접 수정 파일이 겹치지 않으므로 별도 CI 결과 참조)
- 전체 Fieldwire UI 디자인·메뉴·버튼·레이아웃은 도면/디자인 개발 채팅에서 관리. 이 통합은 새 UI 디자인이 아님.

## 충돌과 해결 원칙
1. `DrawingSheetWorkspace.tsx`: 마크업 Canvas, 개정 Dialog, 표제란 검수, 사진 연동을 모두 유지하는 import/상태 조합.
2. `drawing_sheets.py`: 마크업·개정·표제란 검수 3개 API 등록을 순서대로 유지.
3. `drawing-sheet-client.ts`: 마크업 명령과 표제란 검수 API를 모두 보존하며 함수 범위 오류 수정.
4. `CapturePage.tsx`: 사진 자동전송 JSX 오류 보정, 도면 PR의 현장기록 화면 구성 변경과 함께 컴파일.
5. 본 호환성 브랜치는 다른 PR들의 **동결 시점 사본을 조합한 시험용**이다. 소유 채팅의 UI 수정본을 소급해 변경하지 않는다.

## 진행된 검증
- 프론트엔드 TS 타입검사 PASS.
- 프로덕션 빌드 PASS (#231·#233 통합 전 1차 확인).
- Chromium PC/모바일 12개 E2E PASS (#231·#233 통합 전 1차 확인).
- 감리 #231 단독 Python 44건/웹 E2E 12건 PASS.
- 다국어 계약 18건 PASS, GitHub hosted 계약 CI PASS (#233).
- Windows 로컬 drawing HTTP 합본은 RSA 비밀키 파일 ACL 차이로 일부 테스트가 중단되어 **기능 검증 PASS로 판정하지 않는다**.
- GitHub Actions 병행 합본 CI를 최종 증거로 사용해야 한다.

## 인수·병합 기준
- 이 브랜치를 `main`이나 운영서버로 병합하지 않는다.
- 다른 채팅방의 도면 PR #206/#216/#224/#226의 병합 순서·UI 결정이 우선이다.
- CI와 기능별 인수 확인 후 필요한 호환성 조정만 해당 소유 PR에 이관한다.
