# 합성 테스트 프로젝트 4역할 간편 로그인

DOUL 감리앱의 **테스트 서버 전용** 로그인 화면이다.

- 테스트 서버: `DOUL_ENVIRONMENT=staging`, `DOUL_AUTH_MODE=local-password`로 운영한다.
- 운영자가 별도로 `DOUL_TEST_ROLE_LOGIN=synthetic-only`를 설정한 경우에만 로그인 화면에 **발주처·시공사·감리자·어드민** 4개 버튼을 표시한다.
- 사용자가 역할을 선택하면 서버는 `siteTestProject`로 등록한 **합성 테스트 프로젝트**의 기존 역할 배정만 검증하고, 15분짜리 서명된 JWT를 발급한다. 다른 프로젝트의 데이터·멤버십·계정은 제공하지 않는다.
- 간편 로그인 계정은 실제 프로젝트를 추가하거나 다른 프로젝트로 전환할 수 없다. 관리자 역할로 시험 프로젝트 내 설정·인원 요청 처리는 테스트할 수 있다.
- 원래의 비밀번호 로그인 API와 등록된 계정·비밀번호는 보존한다.
- 테스트가 끝나면 **환경변수에서 DOUL_TEST_ROLE_LOGIN 제거 후 API 재기동**한다. 기존 시험 역할 JWT도 재기동된 서버에서 거부한다.
- pilot 및 production 배포에서 이 플래그가 설정되어 있으면 앱 시작이 실패한다. 합성 데이터가 설치되어 있지 않아도 시작하지 않는다.
- 이 모드는 실제 현장 자료/운영 인수시험, 외부 사용자 계정 발급, 실사용 인증 수단으로 사용하지 않는다.

검증은 `tests_mvp.test_synthetic_role_login_http` 및 `playwright.quick-role.config.ts`에서 한다.
